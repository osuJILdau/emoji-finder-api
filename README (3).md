# Emoji Finder — работа с API

Проект на React и TypeScript с Node.js API. Страница сделана по макету Emoji Finder.

Поиск работает через сервер: при изменении текста отправляется новый запрос.

## Как запустить

Установи Node.js, затем открой папку проекта в VS Code.

**1. Запусти сервер в первом терминале:**

```bash
cd server
npm i
node app.js
```

Сервер должен сообщить: `Сервер запущен на http://localhost:3000`.

Проверка: http://localhost:3000/api/emojis

**2. Запусти сайт во втором терминале:**

```bash
cd client
npm i
npm run dev
```

Открой адрес, который покажет Vite (обычно http://localhost:5173).

## Что сделано

- Данные берутся с API `/api/emojis`, а не из готового массива React.
- Есть поиск по названиям и ключевым словам.
- Показываются загрузка, ошибка и пустой результат.
- Для данных используется TypeScript-интерфейс `EmojiItem` без `any`.
- Запросы вынесены в `client/src/api/emojiApi.ts`.
- Макет использует Flex, Grid и шрифт Inter.

## Проверка

Введи `fire` в поиск. Сервер должен вернуть подходящие эмодзи.

Останови сервер и перезагрузи страницу — появится сообщение об ошибке.

В папке `client` можно проверить код командами:

```bash
npm run build
npm run lint
```

Исходный Node.js сервер взят из архива, выданного к практической работе.
